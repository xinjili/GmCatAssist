# 光猫快连 · GmCatAssist

> 给宽带装维用的安卓小工具：**拍一张光猫背面的标签 → 自动认出 WiFi 信息 → 优先连 5G → 一键打开光猫后台**。

装宽带时需要连上光猫的 WiFi 才能进 `192.168.1.1` 做注册开通。光猫背面贴纸上印着 SSID、WiFi 密码、后台地址/账号/密码、SN、MAC，字小、有反光、还常常带油污，站在梯子上手抄一遍很费劲，抄错一位就连不上、白跑一趟。这个 App 就是为了省掉这一遍手抄。

---

## 功能

**拍照识别**
调用视觉大模型读光猫标签贴纸，直接返回结构化字段，而不是一整段文字：

- 无线名称 / WiFi 密码，**2.4G 与 5G 分开两组**
- 后台地址 / 后台账号 / 后台密码
- **SN**（华为光猫支持 `HWTC` 与 `48575443` 两种印法）、MAC、设备型号
- 其他标签信息（PON SN、生产日期等）

**5G 优先**
标签上通常只印一组 SSID 和密码，5G 靠 `-5G` 后缀区分、密码相同。由此推导出两个频段的独立信息后：

1. 拍完照自动扫一次周边，给两个频段标注「已扫到 / 未扫到」
2. 5G 在就默认推荐 5G；5G 不在而 2.4G 在，自动切到 2.4G
3. 连接前再确认一次，扫不到所选频段但另一个在，自动切换并明确告知

**接近一键的连接**
用 Android 的 `Settings.ACTION_WIFI_ADD_NETWORKS` + `WifiNetworkSuggestion` 调起系统「添加网络」弹窗，**SSID 和密码都已预填**，用户点一下即可写入系统 WiFi。

**打开后台**
唤起系统浏览器访问光猫后台地址。不内嵌 WebView —— 注册过程中可能要切页面、看工单，浏览器多标签更顺手，而且浏览器自带密码记忆。

## 关键设计取舍

这个项目里几个不那么显然的决定，以及背后的原因。

### 为什么是独立 App，而不是小程序

Android 10 起 Google 出于安全考虑，移除了第三方应用直接改写系统 WiFi 配置的能力。微信小程序的 `wx.connectWifi` 在 Android 10+ 上只能让**小程序自身**使用该网络，用户切出去依然没网；iOS 上反而可以真正改写系统设置。

所以小程序方案在 Android 上是残废的（只能生成二维码或复制密码），而装维现场主要用安卓。走原生 App 才能用上系统的「添加网络」弹窗。

### 为什么识别必须在连接之前

光猫未开通业务时，连上它的 WiFi 只有内网、没有外网。这意味着**识别请求必须在连接之前完成**，此时手机还在走 4G/5G 流量。这个顺序是硬性的，不能反过来。

连上之后 App 会明确告知「没有外网是正常的」，不会让人对着加载不动怀疑人生。

### 为什么不提取 LOID

LOID / 逻辑 ID 和宽带认证密码**不在光猫标签上**，它们在运营商的装维系统里。

早期版本试过让模型提取 LOID，结果适得其反：标签上没有真实数据时，视觉模型会把 SN 或别的编号硬塞进去，产生一个看起来很像但完全错误的凭据。相比不提取，这种幻觉更有害。

所以识别范围严格限定在标签上确实印着的东西。App 能提供的注册相关硬信息，只有 SN —— 而这恰好是最难手抄、又必填的那一个。

### 为什么自动填充只做前几次

后台登录页各厂商结构不同，脚本注入本身就靠通用启发式（找第一个 text 输入框和 first password 输入框）。如果每次页面跳转都重新注入，登录成功后翻到「修改密码」页就会被误填。所以自动填充有次数上限，且不做自动提交（避免连续失败触发账户锁定）。

## 技术栈

- **Java**，纯原生 SDK，**零第三方依赖**
- minSdk 29（Android 10）/ targetSdk 34
- 视觉识别走 OpenAI 兼容接口（`/chat/completions` + `image_url`），火山方舟、通义、智谱、DeepSeek 等均可
- 构建产物 APK 约 **68 KB**

零依赖不是洁癖，是为了构建稳定 —— 不需要下载任何 AndroidX / 图片库 / 网络库，`gradle assembleRelease` 十几秒出包。

---

## 构建

需要 JDK 17、Android SDK（platform 34）、Gradle 8.2+。

```bash
# 配置 SDK 路径
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

gradle assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

首次构建需联网解析 Android Gradle Plugin 依赖，之后可离线。

## 使用

1. 安装 APK，打开 App
2. 右上角「设置」，填三项：接口 Base URL、API Key、视觉模型名
3. 对着光猫背面标签拍照
4. 核对识别结果（字段都能直接改），点对应卡片里的「连接 5G / 连接 2.4G」
5. 系统弹窗里点「连接」
6. 点「进后台」打开 `192.168.1.1`

**小米 / Redmi 注意**：除「附近的设备」权限外，系统「位置信息」开关也必须打开，否则扫不到周边 WiFi，无法判断 5G 是否存在。

## 隐私

- **不收集任何数据**，无统计、无上报
- 识别图片会发送到你自己配置的模型接口，识别完成后本地临时文件立即删除，不进相册
- API Key 只存在本机 SharedPreferences
- 不保存任何光猫信息，退出即清空

## 已知限制

- 依赖视觉模型的识别质量，标签严重破损、油污、强反光时仍可能认错。App 会针对可疑结果给出提示（密码位数异常、混入全角字符、附近扫不到该 SSID 等），但最终仍需人工核对
- 系统「添加网络」弹窗在少数深度定制 ROM 上可能不出现，此时会降级为「复制密码 + 跳转 WiFi 设置」
- 未做多语言，界面仅中文
